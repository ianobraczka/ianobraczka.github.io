Sistemas em produção

Meetal ERP Platform

ERP industrial e logística Em produção · 2025–presente

Operações de reciclagem e logística industrial tinham superado um backend em DynamoDB, incapaz de sustentar fluxos financeiros e hardware de chão de fábrica. A Meetal passou a rodar em FastAPI e PostgreSQL após uma migração sem downtime, com balanças RS-232 e fluxos estruturados da OpenAI no mesmo núcleo operacional.

  • Migração DynamoDB → FastAPI e PostgreSQL, sem downtime
  • Hardware Comunicação serial RS-232 com balança industrial
  • IA Fluxos estruturados da API OpenAI

Camada de integração

Balança RS-232 → FastAPI → PostgreSQL # API estruturada da OpenAI · AWS Lambda · corte do DynamoDB, sem downtime

  • Python
  • FastAPI
  • PostgreSQL
  • AWS Lambda
  • Docker
  • OpenAI API

Vandal Production Platform

E-commerce de alta concorrência Produção · 2015–2021

Um marketplace de print-on-demand precisava transformar designs de mais de 10 mil artistas em pedidos produzidos, inclusive em picos de tráfego. A plataforma em Rails sustentou mais de 70 mil produtos com Sidekiq e Redis, gateways de pagamento, cálculo de frete e pipelines de produção na AWS S3.

  • Escala 70 mil+ produtos, 10 mil+ artistas
  • Assíncrono Filas pesadas com Sidekiq + Redis
  • Integrações Pagamentos, cálculo de frete e pipelines na AWS S3

Camada de integração

Vitrine → Rails → MongoDB # Sidekiq + Redis → pagamentos, frete, S3, Elasticsearch

  • Ruby on Rails
  • Sidekiq
  • Elasticsearch
  • MongoDB
  • Docker
  • AWS S3

Teaching Assistant (AI)

IA aplicada e EdTech No ar

Professores precisavam de apoio a aulas ancorado em currículo real, e não em saída genérica de modelo. O assistente orquestra o contexto da BNCC e dos frameworks de Massachusetts, conecta-se direto à API REST do Schoology e não persiste dados de estudantes no armazenamento da aplicação.

  • Ancoragem Orquestração de contexto sem alucinação (BNCC e Massachusetts)
  • LMS Conexão direta com a API REST do Schoology
  • Privacidade Nenhum dado de estudante persistido no armazenamento da aplicação

Camada de integração

Prompt do professor → Next.js → Gemini # contexto BNCC + Massachusetts → Schoology REST · nenhum dado de estudante armazenado

  • TypeScript
  • Next.js
  • Google Gemini API
  • TailwindCSS
