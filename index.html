Meetal ERP

ERP industrial e logística Em produção · 2025–presente

A Meetal é uma plataforma ERP B2B em evolução que gerencia estoque, finanças e logística em tempo real para unidades industriais de reciclagem.

Como engenheiro de back-end principal, ajudo a escalar a plataforma em ambientes de produção ativos. Entre as principais iniciativas estão a liderança da migração de arquitetura sem downtime de um modelo serverless em DynamoDB para FastAPI e PostgreSQL, a construção de integrações seriais (RS-232) com balanças industriais no local e a automação de fluxos operacionais com pipelines estruturados da OpenAI.

  • Migração de dados Corte sem downtime do DynamoDB para FastAPI e PostgreSQL
  • Camada de hardware Balança industrial RS-232 e comunicação serial em tempo real
  • Assistente de consultas com IA Assistente em linguagem natural para consultas de usuários com a API da OpenAI

Stack

DynamoDB Python FastAPI PostgreSQL Amazon Web Services Docker OpenAI API Streamlit

ReUsa App

Geoespacial e gestão de recursos hídricos MVP Governo/Concessionárias · 2020–2023

A ReUsa é um aplicativo orientado a dados criado para mapear, gerenciar e comercializar recursos hídricos de reúso em todo o estado do Rio de Janeiro.

Atuando como líder técnico em uma iniciativa que conecta a UERJ, órgãos governamentais e operadoras de água, projetei do zero a aplicação principal e as camadas de dados. As principais entregas incluíram serviços de back-end e fluxos de autenticação, funcionalidades de mapeamento geoespacial com as APIs do Google Maps e a modelagem de fórmulas complexas específicas do domínio para alocação de recursos hídricos.

  • Liderança técnica Arquitetura de ponta a ponta e roadmap técnico entre stakeholders públicos e da indústria
  • Camada geoespacial Integração com a API do Google Maps e mapeamento de ativos e recursos em tempo real
  • Modelagem de domínio Motores de cálculo e modelos de dados especializados para fluxos de reúso industrial

Stack

Java Kotlin Google Firebase Google Maps APIs REST APIs

Vandal Platform

Marketplace de alta escala e logística 5+ anos como líder técnico · 2015–2021

A Vandal é um marketplace de print-on-demand de alto volume que conecta mais de 10.000 artistas independentes a usuários em todo o Brasil.

Ao longo de mais de cinco anos como líder técnico de back-end, fui a principal referência tanto em arquitetura quanto em infraestrutura. Projetei e mantive os motores centrais que lidam com picos de tráfego e flash sales, construí um back-office interno personalizado para as operações do chão de produção e escalei pipelines assíncronos entre gateways de pagamento, transportadoras e fluxos na AWS S3.

  • Escala e vazão 70 mil+ designs ativos e gestão de tráfego de flash sales de alta concorrência
  • Filas assíncronas Pipelines pesados em segundo plano com Sidekiq, Redis e Elasticsearch
  • Núcleo operacional Back-office ERP personalizado e fluxos automatizados de fulfillment da produção

Stack

Ruby on Rails Sidekiq Redis Elasticsearch MongoDB Docker AWS S3

02

IA aplicada

Teaching Assistant Platform

IA aplicada e EdTech PoC open source · Demo ao vivo

Uma plataforma educacional open source projetada para automatizar o planejamento de aulas alinhado ao currículo, atividades interdisciplinares e fluxos de avaliação no LMS.

Projetada e construída de ponta a ponta para eliminar as alucinações comuns de LLMs em ferramentas de sala de aula, a plataforma leva padrões institucionais estruturados diretamente para o fluxo de trabalho dos professores. As principais decisões de arquitetura incluem ancoragem rigorosa de prompts com o Google Gemini, integração REST protegida por OAuth com o LMS Schoology e uma arquitetura stateless com privacidade por design.

  • Ancoragem de contexto Orquestração de schemas few-shot ancorada nos currículos oficiais (BNCC e DLCS)
  • Integração com LMS Conexão com a API REST do Schoology para hierarquias de cursos e sincronização de atividades
  • Privacidade de dados Arquitetura com privacidade por design e zero persistência de dados de estudantes

Stack

TypeScript Next.js Google Gemini API TailwindCSS REST APIs
